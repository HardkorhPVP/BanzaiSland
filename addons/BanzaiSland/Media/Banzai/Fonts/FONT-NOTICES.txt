BANZAI DISPLAY FONTS - NOTICES AND PROVENANCE
=============================================

This folder ships the display faces selectable in the addon's Display Font
setting. The Information Font option uses the addon's existing small font and
adds no file here. Every file below is the unmodified font file as preserved in
the BANZAI source archive; the SHA-256 is the exact shipped file.

Distribution basis: the BANZAI project owner approved shipping these fonts
inside BANZAI UI and BanzaiSland for the Retail release (2026-11-08). The
licence or readme text supplied with each font download is reproduced here
verbatim where one was included in the download. No font is claimed to be
public domain. Fonts remain the property of their respective authors.

Only the display faces listed below are included in this addon.

Automatic selection uses the BANZAI Default face only when it supports every
character of a string; otherwise the whole string is drawn in the Information
Font. A face the game cannot load also falls back to the Information Font.
