# Changes from Island 3.7.0

BanzaiSland is a GPLv3 fork of Island by Devin (subtlegrind). BanzaiSland is
independently maintained and is not supported by the upstream Island author.
The original Island copyright notices and license remain in the addon source.

## BanzaiSland 1.0.0

The 1.0.0 release adds a BANZAI visual system and the following presentation and
configuration changes to the Island 3.7.0 source:

- Bamboo and Hairline chassis; Banzai Glass, Solid, and Hardkorh Parchment
  materials; Banzai, Class, and Hardkorh accents; and original BANZAI class art.
- Additional cards, bubbles, activity and progression views, notifications,
  interactive prompts, previews, and the `BanzaiSlandAPI` extension interface.
- Per-character profiles and configuration, plus optional integration with
  BANZAI UI through the BANZAI SLAND launcher.
- A display-font selector with Shojumaru as BANZAI Default and documented
  alternate faces. Shipped fonts remain unmodified and retain their supplied
  license and attribution notices.
- Retail release metadata, player documentation, release notes, credits, and
  third-party notices.
