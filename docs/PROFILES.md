# Profiles

A **profile** is a complete set of BanzaiSland settings - look, placement, notifications, sounds, card layouts. Every character uses one. **Settings › Profiles**.

## How it works

- Every account starts with one profile, **Default**. New characters use it until you say otherwise.
- Create another (**Create and rename**) and it starts as a copy of what you are looking at now. Name it anything - *Healer*, *Raid*, a character's name.
- **In use** shows which profile this character uses; pick another from the list. A profile change takes effect after the reload the game asks for.
- **Copy, reset and delete** - copy another profile's settings into this one, reset this one to the defaults, or delete a profile (characters using it go back to Default).

## What is per profile and what is shared

Per profile: everything you set in the settings window - material, chassis, accent, display font and fonts, position, idle style, which notifications show, sounds, hold times, card layouts, bubble choices.

Shared across the account, whatever profile: things BanzaiSland *learns* rather than things you choose - flight durations, dungeon run history, progress snapshots, extension registrations, and the package trust switch.

## Characters

Which profile a character uses is kept with the account, so renaming or deleting a profile never loses the assignment, and a new character on the same account can pick up an existing profile straight away.

## Updating BanzaiSland

An update never resets a profile. Settings that a new version adds are filled in with their defaults; everything you set stays as it was. A saved display-font choice that names a face no longer shipped becomes BANZAI Default in every profile.
