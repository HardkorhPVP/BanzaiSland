# Support

## Before you ask

1. Read [TROUBLESHOOTING.md](TROUBLESHOOTING.md) and [KNOWN-ISSUES.md](KNOWN-ISSUES.md).
2. `/reload`.
3. Make sure the original **Island** is not enabled alongside BanzaiSland.

## Where

- **Discord** - https://discord.gg/sv2WNwk2WZ - the *#support* channel for questions, *#bug-reports* for defects, *#feature-requests* for ideas (requests are welcome but not promised for a future release).
- **Issue tracker** - `https://github.com/HardkorhPVP/BanzaiSland/issues` - for reproducible bugs with the details below.
- **Addon page comments** (CurseForge / Wago) are read but Discord and the tracker are faster.

**Please do not report BanzaiSland problems to the Island author.** BanzaiSland is an independent fork and is not supported upstream.

## What to include in a bug report

| | |
|---|---|
| BanzaiSland version | `/bsl status` prints it |
| Client | the game version and flavor (1.0.1: Retail 12.1.5 / Forever 1.60.1) |
| Look | material, chassis, accent, display font (`/bsl status` prints these too) |
| What happened | one or two sentences; what you expected instead |
| How to see it again | steps, if you know them |
| Screenshot | with the island visible; for a Parchment readability report, a full-size (not scaled) crop of the text |
| Lua error | the whole message from the game's error window or BugSack, if there was one |
| Other addons | anything that also touches the XP bar, ready checks, loot rolls or zone text |

## Feature requests

Feature requests are welcome in Discord or GitHub Issues. They are considered after the 1.0 release and are not a commitment to implement a change.

## Security

If you believe you have found a security problem (an extension or package that reaches something it should not), report it privately through Discord to the maintainer rather than in a public channel.
