## Typography

- **BANZAI Default** - *Shojumaru Regular* by Brian J. Bonislawsky DBA Astigmatic (AOETI), Copyright (c) 2012, is the default display face at 105%. The exact runtime file is `addons/BanzaiSland/Media/Banzai/Fonts/Shojumaru-Regular.ttf` (SHA-256 `8607110ef45da664861c72d95fb804c3609169ebfd2a380cb47b353a7b241c75`). Source: [1001Fonts](https://www.1001fonts.com/shojumaru-font.html). It is redistributed under SIL Open Font License 1.1; the required notice and reserved name are preserved in `addons/BanzaiSland/Media/Banzai/Fonts/OFL.txt`. Darren approved Shojumaru as BANZAI Default for the Retail release; the font remains under its OFL terms.
- **Information Font** - *Open Sans ExtraBold* by The Open Sans Project Authors is the explicit display alternative and the whole-string fallback. The runtime file is `addons/BanzaiSland/Media/Fonts/OpenSans-ExtraBold.ttf` (SHA-256 `0fcbdb5cbeea00ae532352c7c94a7d288ebc911ba85f4d595012032dcab64ba8`). Source: [Google Fonts Open Sans](https://github.com/googlefonts/opensans). Preserve the Apache-2.0 and OFL notices in `addons/BanzaiSland/Media/Fonts/`.
- **Alternate display faces** - *Ryujin Attack* (Jetsmax), *Gang of Three* (Vic Fieger), *Osaka Sans* (author not identified in the download; 1001Fonts FFC licence), *Sekaiwo* (Tkzgraphic), *Xangda Shiny* (starinkbrush) and *Ninja Naruto* (sk89q / The Risen Realm and Keiichi Anime Forever) are selectable alternates, shipped unmodified with the licence or readme text supplied in their downloads. None is claimed to be public domain; each remains its author's property. Author, source and SHA-256 for each are in `addons/BanzaiSland/Media/Banzai/Fonts/FONT-NOTICES.txt` and `THIRD_PARTY_NOTICES.md`. An alternate is drawn at its own size (no 105% base) and any string it cannot show uses the Information Font.
- **Automatic** uses BANZAI Default only when the complete display string is supported; otherwise it uses the Information Font. The selected display face remains independent from BANZAI UI.
